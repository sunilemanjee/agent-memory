How Agent Memory Works

One conversation → episodic workflow → the matching semantic entity → three memory layers. Entities are computed, not scripted: Jina clustering embeddings + significant_text discover each user's topics from their own conversation history.

📅 Episodic Workflow
  1. Fetch conversation from Agent Builder API
  2. AI summarizes + extracts topics & entities
  3. Index → episodic_memory
semantic_text auto-embeds via Jina v5
🧠 Semantic Workflow — matched entity only
  1. Embed this conversation (Jina task=clustering)
  2. Cosine-match against this user's cached cluster centroids
  3. Fire only for the best-matching entity(ies) — not every cached topic
  4. AI distills 3–5 facts, merges with existing knowledge
  5. Index → semantic_memory
