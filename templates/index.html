How Agent Memory Works

One conversation → four Kibana Workflows → three memory layers. All stored and retrieved natively in Elasticsearch.

📅 Episodic Workflow
  1. Fetch conversation from Agent Builder API
  2. AI summarizes + extracts topics & entities
  3. Index → episodic_memory
semantic_text auto-embeds via Jina v5
🧠 Semantic Workflow ×3
  1. Fetch all user's episodic memories
  2. AI distills 3–5 facts per knowledge entity
  3. Embed facts → kNN search existing memories
  4. Similarity > 0.75 → merge · else → create
  5. Index → semantic_memory
