How Fire TV Support Memory Works

One conversation → four Kibana Workflows → four memory layers. All stored and retrieved natively in Elasticsearch.

💬
Live Chat
Customer talks to the Fire TV Support Specialist
↓ ⚡ Save to Agent Memory
📅 Episodic Workflow
  1. Fetch conversation from Agent Builder API
  2. AI summarizes + extracts topics
  3. Index → firetv_episodic_memory
🧠 Semantic Workflow
  1. Fetch user's episodes
  2. AI distills standing facts
  3. kNN merge-or-create
  4. Index → firetv_semantic_memory
⚙️ Procedural Workflow
  1. Fetch user's episodes
  2. AI extracts personalized playbook
  3. Index → firetv_procedural_memory
🛠️ Remediation Workflow
  1. Fetch episodes + canonical ladder + warranty
  2. AI tracks steps tried vs. remaining
  3. If ladder exhausted & out of warranty → offer 10% off
  4. Index → firetv_remediation_memory
